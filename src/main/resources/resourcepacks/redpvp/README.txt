Red PvP Cartoon - Minecraft Java 1.21.4 (pack_format 46)

Install: put the .zip (not unpacked) into .minecraft/resourcepacks, then enable it under Options > Resource Packs.

Not possible with a resource pack - set in game instead:
  Options > Accessibility Settings > Damage Tilt = 0%   (no hurt camera shake)

Where to tweak things (all plain PNGs under assets/minecraft/textures):
  gui/sprites/hud/            hotbar, selection frame, offhand, effect icons background
  item/*_sword.png            swords (16x16)
  particle/                   critical_hit, sweep_*, effect_* (potion/poison swirls), spell_*
  block/fire_1.png            low fire overlay - delete this file (and .mcmeta) for vanilla fire
  painting/, gui/title/background/   your images
Delete any folder to go back to the vanilla look for that part.
